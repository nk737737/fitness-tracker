# Fitness Tracker

A workout tracking web application built with HTML, CSS, and JavaScript.

## Features

- Add workouts with a type, duration, date, and optional notes.
- Validate workout details before adding them.
- Delete workouts and automatically update statistics.
- Search workouts by ID or notes.
- Filter workouts by type.
- Sort workouts by duration.
- View workout statistics and summaries.
- Responsive layout using CSS Flexbox and Grid.

## Technologies Used

- HTML5 — semantic page structure
- CSS3 — Flexbox, Grid, and styling
- JavaScript — DOM manipulation, events, array methods, and validation
- Git and GitHub — version control
